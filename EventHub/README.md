# EventHub - Event & Venue Booking Platform

EventHub is a modern web application for discovering events, booking tickets, and renting venue plots.

## Key Features
- **Event Discovery & Ticket Booking**: Browse live events, filter by category (including Comedy, Tech, Music, Sports), select seats, and download PDF tickets with QR verification.
- **Venue Rental System**: Book venue grounds, party plots, resorts, and auditoriums with optional catering, DJ, and decoration services.
- **Direct Messaging**: Two-way direct chat between Venue Owners and Organizers/Customers with real-time notifications.
- **Ticket Scanner**: In-app QR ticket scanner for event entry gate verification.
- **Executive Dashboards**: Custom dashboards for Customers, Organizers, Plot Owners, and Platform Administrators.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Lucide Icons.
- **Backend**: Django, Django REST Framework, SQLite.
