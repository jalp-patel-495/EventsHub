# 🎪 EventHub - Full Stack Event Management Platform
> A premium event hosting, ticketing, and venue-booking experience for Ahmedabad.

EventHub is a modern, responsive web application designed for discovering, booking, and managing events, party plots, auditoriums, banquets, and resorts.

---

## 🌟 Key Features
- **Event Exploration & Booking**: Interactive search, date filtering, and ticket reservations.
- **Venue Booking**: Book auditoriums, party plots, resorts, and exhibition grounds.
- **AI Chatbot Assistant**: Smart assistant to help users find events and answer queries.
- **User Dashboards**: Dedicated interfaces for Customers, Plot Owners, and System Administrators.
- **Payment & Reviews**: Integrated mock payment flow and user review rating system.

---

## 🛠️ Technology Stack
- **Frontend**: React, TailwindCSS, Vite, Lucide Icons
- **Backend**: Python, Django REST Framework, SQLite
- **Authentication**: JWT (JSON Web Tokens) with OTP Verification, SMTP Modul

## 🚀 Getting Started

### Backend Setup
```bash
cd EventHub/backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```

### Frontend Setup
```bash
cd EventHub/frontend
npm install
npm run dev
```
